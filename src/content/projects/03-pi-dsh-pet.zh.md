一条生活在 **pi** 终端编程助手里的大肥鱼。它会在空闲时呼吸，会随机做出包括打瞌睡在内的动作，偶尔转身、在屏幕上游走、响应点击，还可以拖动。

## 起源

这是 `dsh-pet` 的 fork（上游也发布在 npm），针对 pi 平台重新改造。README 明确区分了两者：已有 `dsh-pet` 用户应继续使用上游 npm 包；这个 fork 增加的是 pi 集成。桌宠会响应 pi agent 的工作状态，由 pi 扩展通过 HTTP 和 WebSocket 驱动全屏透明 Electron 覆盖层。

## 响应 agent

| pi agent 状态 | 桌宠动画 |
|---|---|
| 开始思考 | 深度思考和嘟囔 |
| 调用工具（`bash` / `edit` / `write`） | 写代码 |
| 空闲 | 回到随机动画链 |

在思考或写代码时点击桌宠，会先播放傲娇的「被打扰」反应，然后回到当前状态动画。

## 用法

```sh
npm install -g pi-dsh-pet
```

在 pi 中：

- `/pet`：普通尺寸（400 px）
- `/pet small`：小尺寸（260 px）
- `/pet large`：大尺寸（540 px）
- `/pet-stop`：关闭所有桌宠窗口

第一次运行会下载 Electron（约 100 MB），之后启动会很快。桌宠出现在右下角。

## 尺寸

尺寸位于 `pi/assets/pet.js` 的 `SIZE_MAP` 对象中，高度按宽度 × 9/16 自动计算。在那里添加一个档位后，不需要其他改动就会自动获得对应的 `/pet <tier>` 命令。
