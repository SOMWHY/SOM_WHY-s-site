一个运行在自己电脑上的视频剪辑工具。浏览器负责预览和编辑，本地 Python 服务负责下载、裁剪和 GIF 转码，视频不会上传到服务器。

## 当前支持

根据 README：

- **平台**：支持通过 BV 号、`bilibili.com` 链接和 `b23.tv` 短链接使用哔哩哔哩；YouTube、Vimeo 和 X/Twitter 标记为欢迎贡献
- **操作系统**：Windows 10/11 完全支持；macOS 和 Linux 有实验性的占位脚本；目前不支持 Docker
- **GIF 导出**：支持裁剪、自定义尺寸、速度和质量控制；时间轴胶片缩略图尚未实现
- **界面**：适配窄屏并遵守 `prefers-reduced-motion`

## 导出选项

宽度可以选择 320 / 480 / 640 px，也可以填写 64 到 1280 之间的自定义值；省略高度时按比例计算，宽高比不一致时使用留白而不是拉伸。速度可选 0.5× / 1× / 1.5× / 2×，只改变播放时长，不改变选区。FPS 可选 5 / 10 / 15 / 20，调色板可选 64 / 128 / 256 色，抖动支持 Bayer 或 Sierra 2-4A。

默认值是：不裁剪、宽度上限 480 px（不放大）、12 FPS、1×、128 色、Sierra 2-4A。

选区不能超过 60 秒，导出的 GIF 不能超过 50 MB。

## 备注

登录后的视频可以通过用户自己的 Netscape 格式 `cookies.txt` 使用。README 特别强调 cookies 是凭据，绝不能共享或提交到仓库。源视频、预览和 GIF 分别写入 `work/`、`previews/` 和 `outputs/`，不会自动清理。
